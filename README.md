# MapHeim

A Valheim (BepInEx) mod for the corner map: a **dungeon plan** that grows as you explore (only ~10 ft ahead of you is revealed), **zoom** (`[` / `]`, or Ctrl + wheel) and a 90-second **trail** of where you've been, a **GPS** with distance and ETA, **auto pins** for rune stones, dungeons and ore, and a **repair for oversized cartographer's tables**.

- Thunderstore description: [package/README.md](package/README.md)
- Build: `./build.sh` (uses `~/.dotnet`; game assemblies in git-ignored `libs/Managed`), which zips `dist/MapHeim-<version>.zip`.
- Untested in game at the moment.

Part of the Svaha Valheim mods; see the index in the parent folder.
